# FoodRescue — Project Overview

## 1. Introduction
FoodRescue is a web-based food donation platform designed to connect restaurants with NGOs to facilitate the donation of surplus edible food.

## 2. Problem Statement
Restaurants may have surplus edible food at the end of the day, while NGOs need food to distribute to people in need. Coordinating donations, requests, and pickups manually can be difficult.

## 3. Proposed Solution
FoodRescue provides a centralized platform where restaurants can publish available food donations, NGOs can browse and request them, and both parties can coordinate pickups and track donation status.

## 4. Objectives
- Reduce avoidable food wastage.
- Connect restaurants with NGOs.
- Simplify food donation requests and pickup coordination.
- Maintain donation and request histories.
- Provide administrators with basic platform management and statistics.

## 5. Target Users
- **Restaurants:** Publish and manage surplus-food listings.
- **NGOs:** Browse donations, request food, and coordinate collection.
- **Administrators:** Manage user accounts and monitor platform activity.

## 6. Main Features
1. User registration and login
2. Restaurant food listings
3. Browse and filter available food
4. Donation requests and restaurant decisions
5. Pickup coordination and status tracking
6. Donation history
7. Admin dashboard

## 7. Technology Stack
- Frontend: HTML, CSS, JavaScript, Bootstrap
- Backend: Python Flask
- Database: MySQL
- Version Control: Git and GitHub

## 8. Development Methodology
The project will follow Agile development using Scrum, with work divided into sprints, regular reviews, and continuous testing.

## 9. Project Outcome
The expected outcome is a working web application that demonstrates the complete food donation workflow, from publishing a food listing to recording its collection.
